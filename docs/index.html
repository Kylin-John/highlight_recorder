Features

为游戏而生,也为体验较真

原项目的循环回录与音视频管理,加上 Kylin 开发的接续保存、预计时长、浮窗设置与游戏呈现帧率监测。

⏪

时光倒流式录制

环形缓冲常驻内存,只留最近 N+2 秒。先开启循环录制,精彩时刻发生后再按保存;按关键帧边界导出,不会自动保存整场对局。

🎈

悬浮球随叫随到

全屏游戏之上依旧可点。可拖动、松手自动贴边、透明度可调,呼吸红点提示录制状态。录制时单击保存,长按可选直接停止或保存后停止。

⚡

硬件级性能

VirtualDisplay 直送 MediaCodec 输入面,全程零 Bitmap、零帧拷贝;编码声明 best-effort 优先级。实际耗电、发热和游戏影响取决于设备与参数,需要对照测量。

🔊

音画同录,还能混音

内录游戏原声(AudioPlaybackCapture)、麦克风解说,或两者实时混音——PCM 相加截幅合成单音轨,通过支持相应编码的播放器回放。

🛡️

稳字当头

前台服务 + 常驻通知;低电量、低内存时降低码率并提示,内存危急时结束录制。编码停滞时尝试有限次数恢复;系统终止会话后需重新开始。

📊

游戏呈现帧率监测

Kylin 新增:通过 Shizuku 读取目标游戏图层的实际呈现时间戳,显示 FPS、曲线、均值与 1% low。可独立监测或随录制运行,依赖系统提供有效数据,不解锁游戏帧率。

⏩

接续保存与浮窗选择

Kylin 新增:可选接续保存减少重复素材,主页展示预计成片秒数。浮窗可显示「存」、FPS 或预计秒数;主页统一选择监测游戏,常用应用靠前。

🎛️

参数全可调

回退时长 / 分辨率(720p~4K) / 帧率(30~120fps) / 码率 / H.264·H.265 / 音频来源 / 悬浮窗外观,显示内存与体积预估;编码参数在新录制中应用,浮窗设置可在当前会话更新。深浅双色主题,跟随系统自动切换。

Getting Started

四步,存下第一个高光

安装并授权

首次打开引导页,逐项授予悬浮窗、通知等权限,每步都有"为什么需要它"的说明。

开始循环录制

主页一键开始,每次新会话都需确认系统录屏弹窗,随后在后台持续缓冲;FPS 目标在主页选择。

打出高光,点一下

五杀?神钩?单击悬浮球,按当前模式在后台封装为 MP4,导出期间继续采集;等待保存成功提示。

回放与分享

视频库内查看缩略图、时长与大小,一键播放、分享给队友;长按多选,批量分享或清理。

Under the Hood

环形缓冲 + 关键帧对齐

编码输出按实际到达的 IDR 关键帧切片,目标间隔约 1 秒;保存从关键帧起始并将 PTS 重定基。关键帧间隔与实际缓冲会影响成片时长。

更新日志

v1.2.3.6 2026-10-30 · Kylin Fork

新增 Shizuku 游戏呈现 FPS 监测和独立监测,保留最近报告;自动匹配唯一 BLAST 图层并记住成功特征,常用应用靠前。主页统一选择监测目标,浮窗显示三选一,设置选中态更清晰。应用名为高光回录,附件为 HighlightRecorder-v1.2.3.6-debug.apk。具体使用条件和统计定义见 README。

v1.2.3.2 2026-10-29 · Fork

主页保留缓存总量,新增当前保存模式下的预计成片秒数;接续保存成功后仍计入导出期间采集的内容。浮窗长按可选直接停止或保存后停止,默认保持直接停止;保存失败继续录制,已有导出时提示稍后重试。沿用独立包标识与原有 debug 签名。

v1.2.3.1 2026-10-29 · Fork

新增可选的接续保存模式,减少连续回录的重复素材;默认仍为每次保存最近 N 秒。点击时固定导出尾部,保存成功后才推进接续边界,导出期间继续采集。APK 文件名为 app-debug.apk,沿用独立包标识与原有 debug 签名。

v1.2.3 2026-09-13

回退时长上限提升至 5 分钟;分辨率新增 2K/4K 档位,帧率新增 90/120fps,自定义码率上限 60Mbps(高码率缓冲安全阀动态扩容,防 OOM);修复高负载下音画不同步(音频时间戳改用硬件时钟锚定 + 丢帧补偿);音频录制失败时通知栏明确提示;新增录制看门狗,画面中断自动恢复(修复部分机型小窗口后缓冲归零);修复侧滑手势返回后页面灰屏/白屏(弃用 navigation-compose,导航完全自控);页面适配状态栏与手势条间距;缓冲为空时点保存有明确提示。

v1.1.4 2026-08-28

修复旋转屏幕导致录制中断(SecurityException / IllegalStateException)与悬浮窗丢失;修复长时间录制内存溢出(编码器不发关键帧时缓冲无限增长);修复部分机型「跟随屏幕」启动失败(编码器长边超限自动收敛);悬浮球位置按比例记忆,旋转不跑偏;主页新增防杀后台提示;设置页显示版本号。
